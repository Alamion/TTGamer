# Contract: Shipped Entity Templates (Star Wars WoD)

Page outlines for the six new shipped templates. Node ids listed here are stable: documentation embeds and tests reference them. Coordinates are defined in [data-model.md](../data-model.md) §1–2. Presentation follows the character page (alternating accents, wide centered layout). `▸` = collapsed by default; `docs:` = section rules link.

## Catalog fill mappings

| Select                                  | Target ← catalog detail                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `species-catalog` (creatures)           | `field:species` ← name; `field:type` ← type; `field:scale` ← scale→enum; `field:size` ← size; `trait:*` ← attribute dice→dots; `resource:willpower` ← willpower dice→pair; `list:abilities` ← abilities; `field:armor.*` ← armor split; `table:attacks` ← attacks; `movement`; `creature-merits` ← merits; `creature-flaws` ← flaws; `description`; `source`                                                                                                            |
| `model-catalog` (vehicles)              | `field:model` ← model; `field:scale` ← scale→enum; `category`; `field:crew`; `field:passengers`; `field:cargoCapacity` ← cargo; `field:consumables`; `field:length`; `trait:maneuverability`, `trait:durability`, `trait:hyperdrive` (null→0), `trait:communicationsSensors` ← commSensors, `trait:shields`; `durability-reroll`; `field:speed`, `field:altitude`, `field:navigationComputer`, `field:sensorRange`; `table:weapons` ← weapons (arc→enum); `description` |
| fodder armor select (armor)             | `field:armor.name`, `field:armor.armorRating` ← ar, `field:armor.dexterityModifier` ← dexPenalty                                                                                                                                                                                                                                                                                                                                                                        |
| fodder weapon row select (ranged/melee) | row `name`, `damage`, `range`                                                                                                                                                                                                                                                                                                                                                                                                                                           |

Semantics: [catalog-fill.md](./catalog-fill.md).
