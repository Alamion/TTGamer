# Мир Тьмы, 5-я редакция

:::tip[Коротко]
V5 — это единый свод правил для нескольких современных хоррор-игр. Один раз разберитесь с основой в разделе **Общие правила**, а потом выберите линейку. Сейчас можно играть в **«Охотник: Воздаяние»**.
:::

Пятая редакция Мира Тьмы — это семейство игр о внешне обычных людях в мире, где монстры реальны. Каждая игра («линейка») даёт вам свою роль — охотников, которые сражаются с монстрами, или самих монстров, — но все они работают на одном движке: пулы десятигранных кубиков, простые рейтинги в точках и урон, который постепенно вас изматывает.

Этот раздел устроен так же. **Общие правила** объясняют движок, которым пользуются все линейки. У каждой линейки есть свой раздел с быстрым стартом, пошаговым созданием персонажа и справочником по её особым правилам.

| Линейка                          | Статус на сайте              |
| -------------------------------- | ---------------------------- |
| Охотник: Воздаяние, 5-я редакция | Доступны лист и документация |
| Вампир: Маскарад, 5-я редакция   | Запланировано                |
