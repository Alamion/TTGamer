# Типы документов и сеттинги

:::tip[Коротко]
Страница принадлежит одному типу документа в одном сеттинге. Её можно перенести, дать своему сеттингу собственные типы документов из страниц и собрать целый сеттинг на правилах, которые сайт уже поддерживает.
:::

## Перенос страницы \{#moving-a-page}

**Тип и сеттинг** вверху редактора показывает, для каких документов страница. Выберите другой пункт, чтобы перенести её: к другому типу той же игры, к одному из своих типов или к персонажу своего сеттинга.

При сохранении перенесённой страницы:

- документы, которые открывались на ней и больше не могут её использовать, возвращаются на страницу по умолчанию — редактор сначала спросит и скажет, сколько их;
- если это была страница одного из ваших сеттингов, сеттинг её забывает; если у сеттинга, куда вы её перенесли, для этого персонажа ещё нет страницы, она становится ею;
- если это была страница по умолчанию одного из ваших типов документов, тип берёт другую свою страницу.

Значения, привязанные к данным игры, которых у нового типа нет, попадают в список проблем до сохранения: переключите такие поля на свои значения или удалите их.

Встроенные страницы остаются на месте; так же остаются первая страница нового типа документа и страница сеттинга, открытая из самого сеттинга.

## Свои типы документов \{#document-types}

**Новый тип документа** в библиотеке шаблонов создаёт тип — организацию, судовой журнал, место — в любом сеттинге и открывает его первую страницу. Его документы появляются в **Создать документ** рядом с типами самого сеттинга. Все значения такого документа хранятся вместе с документом, поэтому изменение или удаление страниц типа не теряет данных: документ, чей тип удалён, открывается на странице со списком сохранённых значений.

## Свои сеттинги \{#settings}

**Новый сеттинг** строит сеттинг на правилах, которые поддерживает сайт, — Мир Тьмы 2-й или 5-й редакции. Его персонажи следуют этим правилам (кубики, пределы) на странице, которую вы собираете через **Страница: Персонаж**, а ваши типы документов могут принадлежать ему.

## Обмен через файлы \{#files}

**Экспортировать тип** сохраняет тип документа со страницами в один файл; импорт в библиотеке шаблонов устанавливает его. Документ вашего типа несёт свой тип внутри файла, поэтому открывается и там, где тип не установлен.
