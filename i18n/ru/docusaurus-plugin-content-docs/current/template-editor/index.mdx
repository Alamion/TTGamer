# Редактор шаблонов

:::tip[Коротко]
Шаблон — это раскладка страницы документа. Откройте **Библиотеку** на [листе персонажа](/universal_sheet), выберите страницу в [дереве библиотеки](./library), откройте её в редакторе и меняйте прямо на ней: выберите элемент, чтобы увидеть его настройки, перетащите, чтобы переместить, и нажмите **Сохранить**, когда список проблем пуст.
:::

Каждый документ открывается на странице: какие блоки на ней есть, где они стоят и какие значения хранят. Страницы, которые идут вместе с игрой, — **встроенные**; их можно менять, копировать или собрать свою с нуля. Значок **?** рядом с настройкой в редакторе открывает нужную часть этого руководства.

## Три области \{#areas}

| Область       | Для чего                                                                                                    |
| ------------- | ----------------------------------------------------------------------------------------------------------- |
| **Структура** | Дерево всех элементов страницы. Щелчок по строке выбирает элемент; за рукоять его можно перетащить.         |
| **Страница**  | Страница ровно такой, какой её видит читатель, с пробными данными. Щелчок по элементу выбирает его.         |
| **Настройки** | Всё, что умеет выбранный элемент, в одних и тех же группах для любого элемента: см. [Настройки](#settings). |

Перетащите линию между двумя областями, чтобы сделать структуру или настройки шире; странице всегда остаётся хотя бы ширина телефона. Линию в фокусе двигают и клавиши `←` и `→` (с `Shift` — большими шагами), а `Home` или двойной щелчок возвращает её на место. Ширины запоминаются на этом устройстве для всех страниц, которые вы правите.

На узком экране три области становятся вкладками. Элементы, скрытые условием показа, в редакторе остаются видны — заштрихованными, — чтобы их можно было выбрать.

Пробные данные только для просмотра: точки, клетки и текст, изменённые на странице редактора, не попадают в ваши документы.

## Настройки \{#settings}

Настройки выбранного элемента начинаются с действий (выше, ниже, дублировать, удалить), под ними — вид и полное имя элемента. Дальше настройки идут в одних и тех же группах и в одном порядке для любого элемента; группа, в которой элементу нечего показать, пропускается:

| Группа                  | Что в ней                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------- |
| **Содержимое**          | Что показывает элемент: вид, заголовок или подпись, подсказка, варианты, записи.      |
| **Значение**            | Где хранится значение: источник, ключ значения, каталоги.                             |
| **Пределы и формулы**   | Границы и все формулы: минимум и максимум из значений, вычисляемые значения.          |
| **Вид**                 | Как элемент нарисован: колонки, представление, отображение, вид трекера.              |
| **Видимость и справка** | Когда элемент виден и что подсказывает читателю: условия, документация, сворачивание. |

Группа сворачивается по заголовку; открытые группы остаются открытыми, пока вы выбираете другие элементы. Свёрнутая группа, в которой есть проблема элемента, показывает их число.

У каждой настройки есть название над полем. Поле формулы отмечено знаком **fx** и сразу под собой пишет, что формула читает или что в ней не так. Ключ значения начинается с **#**: это имя значения, а не текст для читателя.

## Правка и превью \{#preview}

Переключатель **Правка / Превью** вверху показывает страницу без пометок редактора. В режиме **Превью** можно выбрать данные:

- **Открытый документ** — документ, открытый на листе, если он подходит к этой странице;
- встроенный **пример** для этого типа документа, если игра его даёт;
- **Пустой документ** — все значения пустые, чтобы проверить, как страница выглядит в начале.

Превью никогда не меняет выбранный документ.

## Расстановка элементов \{#arranging}

- **Добавить**: каждый **+** между элементами и каждая пустая колонка вставляет туда новый элемент — [группу](./elements#sections), поле, [список](./elements#lists) или трекер. Группа, добавленная на страницу, — раздел, внутри другой группы — карточка.
- **Переместить**: перетащите элемент за его ярлык на странице или за рукоять в структуре. Линия отмечает ближайшее место, куда его можно поставить, — между элементами, внутри группы или в пустой колонке, — даже когда указатель над другим элементом. Задержитесь на мгновение, и страница покажет элемент на новом месте, а там, где он был, — пунктир. Отпустите, чтобы переместить (один шаг **Отмены**), или нажмите `Escape`, чтобы всё осталось как было. У верхнего и нижнего края страница прокручивается. На сенсорных экранах используйте кнопки перемещения в настройках.
- **Клавиатура**: сочетания работают в любой раскладке.

| Клавиши                   | Действие                             |
| ------------------------- | ------------------------------------ |
| `Ctrl+X`                  | Вырезать                             |
| `Ctrl+C`                  | Копировать                           |
| `Ctrl+V`                  | Вставить                             |
| `Ctrl+D`                  | Дублировать                          |
| `Delete`                  | Удалить                              |
| `?`                       | Показать этот список клавиш          |
| `Ctrl+клик`               | Добавить элемент к выбору или убрать |
| `Shift+клик`              | Выбрать элементы между               |
| `Esc`                     | Снять выбор                          |
| `Alt+↑`                   | Переместить выше                     |
| `Alt+↓`                   | Переместить ниже                     |
| `Alt+←`                   | Вынести из группы                    |
| `Alt+→`                   | Перенести в группу выше              |
| `Alt+Shift+←`             | В предыдущую колонку                 |
| `Alt+Shift+→`             | В следующую колонку                  |
| `Ctrl+Z`                  | Отменить                             |
| `Ctrl+Shift+Z` / `Ctrl+Y` | Повторить                            |

На Mac вместо `Ctrl` нажимайте `⌘`, вместо `Alt` — `⌥`; `⌫` тоже удаляет. Кнопка **Клавиши редактора** (или `?`) показывает этот список прямо в редакторе.

Отмена работает для всех изменений с открытия редактора; набор текста в одном поле считается одним шагом.

## Сохранение и проблемы \{#saving}

Изменения остаются в редакторе, пока вы не нажмёте **Сохранить**. Над кнопкой редактор простыми словами перечисляет то, что сломает страницу, и называет элемент: пустую подпись, запись списка или колонку таблицы без названия, формулу с ошибкой, значение, которого нет, неверную ссылку на документацию. Щелчок по проблеме выбирает элемент, открывает его группу настроек и ставит курсор в настройку, которую нужно исправить, — в том числе внутри колонки таблицы. **Сохранить** недоступна, пока в списке есть такие проблемы. Если при сохранении всё же найдётся недопустимое значение, редактор скажет, в каком элементе и какой настройке, и ничего не сохранит.

Если закрыть редактор с несохранёнными изменениями, он спросит, прежде чем их отбросить.

## Встроенные страницы \{#shipped-pages}

Изменения встроенной страницы сохраняются как ваша версия; все документы на этой странице сразу показывают её. **Вернуть оригинал** в библиотеке возвращает исходную — значения документов сохраняются. Встроенные страницы нельзя удалить; **Дублируйте** такую страницу, чтобы начать с неё свою.
