# Значения, формулы и условия

:::tip[Коротко]
Каждое поле хранит значение под ключом. Поля с одинаковым ключом делят одно значение — в том числе между страницами. Формулы считают числа по этим ключам, а условия показывают элементы, только пока значение совпадает.
:::

## Где хранится значение \{#value-source}

**Где хранится значение** выбирает, где живёт значение поля:

- **Своё значение (в шаблоне)** — поле хранит собственное значение в документе;
- значение, которое игра уже ведёт для документа, — **Характеристики**, **Ресурсы**, **Сведения о персонаже**. Тогда поле показывает и меняет это значение, и кубики, другие страницы и остальной лист видят то же число. Тип поля следует за значением игры.

## Общий ключ значения \{#shared-value-key}

Каждое своё значение хранится под ключом — по умолчанию это идентификатор самого поля. **Общий ключ значения** задаёт ключ вручную: строчные латинские буквы, цифры и дефисы (`reputation`, `ship-name`).

Поля с одинаковым ключом делят одно значение:

- на **одной странице** два поля с ключом `reputation` показывают одно число, и изменение одного меняет другое;
- на **разных страницах** одного документа поле сохраняет значение, когда читатель переключает страницу: краткая карточка и полный лист могут показывать одну `reputation`;
- ключ, совпадающий со значением игры (например `strength`), связывает поле с этим значением.

Удаление поля никогда не стирает его значение: верните поле с тем же ключом, и значение окажется на месте. У таблиц и списков есть свой общий ключ для их строк.

## Формулы \{#formulas}

**Вычисляемое значение** показывает число, посчитанное из других значений. В формулах можно использовать ключи значений, числа, `+ - * /`, скобки и `min(…)` / `max(…)`:

```text
passion + self-control
max(0, reputation - 2)
willpower.max
```

У значений с текущим и максимумом `.current` и `.max` выбирают одно из них. Редактор подсказывает известные ему ключи. Формула с ошибкой, ссылка на несуществующее значение или зависимость от самой себя попадают в список проблем; на странице сломанная формула объясняет причину вместо неверного числа.

## Пределы из значений \{#limits-from-values}

Рейтинг или число может брать максимум из значения или формулы: **Максимум из значения или формулы** со значением `willpower.max` держит рейтинг не выше текущего максимума. Встроенные части страниц берут максимум так же, а встроенные ресурсы — ещё и минимум (**Минимум из значения или формулы**). Если предел опускается, страница показывает значение обрезанным, но хранит прежнее; поднимите предел — и старое значение вернётся.

## Условия показа \{#display-conditions}

**Показывать только при совпадении значения** скрывает элемент, если значение не равно заданному: **Ключ значения** называет значение, **Сравнение** выбирает «равно» или «не равно», **Значение** — с чем сравнивать (`true`, `false`, число или текст).

Редактор всегда показывает элементы с условием — заштрихованными — и сообщает, выполнено ли условие на пробных данных. Скрытие никогда не удаляет значения элемента.

## Каталоги \{#catalogs}

Поле **Выбор** может брать варианты из каталога игры — оружие, достоинства, виды. Выбор записи может заполнить другие поля страницы её сведениями (урон, цена, описание): укажите, какое сведение в какое поле. Заполненные значения — копии; читатель может их менять.
