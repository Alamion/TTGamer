# Дисциплины и способности

:::tip[Коротко]
У каждой **Дисциплины** есть способности уровней от 1 до 5. Брать можно способности уровня не выше ваших точек, по одной на точку. **Проверки жажды** способности — её цена в крови; способности-**амальгамы** требуют ещё и точек во второй Дисциплине.
:::

## Способности

Фильтруйте по уровню или ищите по названию. Выберите способность, чтобы увидеть, что она делает и какой у неё обычный пул. На листе таблица **Способности** предлагает эти названия, сама заполняет уровень и стоимость и даёт способности, которая стоит крови, свою кнопку **Проверка жажды** (Rouse check).

## Ритуалы, церемонии и формулы

У Кровавой магии есть **ритуалы**, у Забвения — **церемонии**, у Слабокровной алхимии — **формулы**. Их проведение занимает время, и учатся им по одному, каждому — не выше уровня его Дисциплины; сколько их у персонажа в начале, спросите Рассказчика. Лист показывает таблицу **Ритуалы, церемонии и формулы**, когда у вас есть одна из этих Дисциплин.
