# Типы хищника

:::tip[Коротко]
Тип хищника (Predator type) — привычный способ питания вампира. Каждый даёт выбор **специализации**, одну **точку в Дисциплине** и несколько **достоинств** и **недостатков**; некоторые ещё меняют Человечность (Humanity) или Силу крови либо закрыты для какого-то клана.
:::

Ищите по названию. Выберите строку, чтобы увидеть описание и что даёт тип. На листе поле **Тип хищника** подсказывает эти названия, а **Что даёт тип хищника** показывает, что даёт выбранный тип.
