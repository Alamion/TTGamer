# Общие правила

:::tip[Коротко]
Три страницы охватывают всё, что объединяет линейки V5: как устроен бросок, что значат ваши характеристики и как отмечаются урон и Сила воли. Каждая линейка добавляет поверх что-то своё.
:::

Эти страницы написаны для игроков любой линейки V5. Если линейка что-то меняет, об этом говорится в её собственной документации со ссылкой сюда.
