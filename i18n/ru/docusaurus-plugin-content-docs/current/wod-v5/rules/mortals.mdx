# Смертные \{#mortal}

**Смертный** — обычный живой человек без особых черт охотника и неживой природы вампира. Полный лист Смертного представляет базового персонажа V5 с отдельными Атрибутами, Навыками, Здоровьем (Health), Волей (Willpower), отношениями и имуществом. Он подробно описывает человека; сам по себе человеческий облик не делает его упрощённым противником.

:::tip[Коротко]
Используйте полный лист Смертного, когда важны отдельные черты. Лист персонажа рассказчика подходит, когда для встреченного игроками человека достаточно нескольких общих пулов.
:::

Смертный может быть персонажем игрока или тем, кого ведёт Рассказчик. Эта роль не определяет выбор листа: постоянному участнику расследования могут понадобиться полные черты, а случайному свидетелю — лишь несколько [пулов персонажа рассказчика](../storyteller/storyteller-characters.mdx#standard-pools).

Об основных числах см. [Атрибуты и Навыки](./attributes-skills.mdx) и [Здоровье (Health) и Воля (Willpower)](./damage-willpower.mdx). Правила сверхъестественных персонажей относятся к их игровой линейке; лист Смертного сам не даёт этих способностей и ресурсов.
