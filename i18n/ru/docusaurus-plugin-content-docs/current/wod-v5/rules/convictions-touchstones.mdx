# Опоры и Убеждённости \{#touchstones-and-convictions}

**Убеждённость** (Conviction) — личный принцип, которым персонаж руководствуется в своих решениях. **Опора** (Touchstone) — человек, связанный с этим принципом: его место в жизни персонажа делает принцип личным. Каждая пара связывает то, во что верит персонаж, с человеком, который придаёт этой вере смысл.

:::tip[Коротко]
Убеждённость принадлежит одному персонажу; Опора — человек, связанный с ней.
Принципы хроники (Chronicle Tenets) — принципы, о которых вся группа договорилась для общей истории.
:::

Для смертного персонажа Убеждённостью может быть _Никогда не бросать того, кому нужна помощь_, а её Опорой — _Мара, соседка, которая меня приютила_. Парные столбцы указывают человека и связанный с ним принцип. На эти отношения и принципы можно опираться при отыгрыше персонажа.

## Принципы хроники \{#chronicle-tenets}

**Принципы хроники** — принципы, о которых игроки и Рассказчик договариваются для своей **хроники**, продолжающейся истории, которую рассказывают на игровых встречах. Они задают общие моральные ориентиры для группы, тогда как Убеждённость описывает личный принцип одного персонажа.

В поле хранятся согласованные принципы, например _Защищать тех, кто попал под перекрёстный огонь_ и _Не предавать того, кто просит убежища_. Эти общие описания не наделяют смертных персонажей ресурсами или последствиями из отдельных игровых линеек; механические эффекты определяются правилами соответствующей игры.
