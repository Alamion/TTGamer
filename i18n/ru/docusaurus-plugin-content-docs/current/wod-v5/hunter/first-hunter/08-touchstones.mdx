# Опоры и убеждения \{#touchstones}

**Опоры** (Touchstone) — люди, связывающие охотника с обычной жизнью; **Убеждённости** (Conviction) — личные принципы, связанные с этими людьми. В каждой строке человек стоит рядом с принципом, который он поддерживает: «Марк, мой брат» — «Никогда никого не бросать».

_Шаг 8 из 9_

:::tip[Коротко]
Назовите одну или две **Опоры** — реальных людей из жизни охотника — и дайте каждой **Убеждённость** (Conviction): правило, по которому охотник живёт ради этого человека.
:::

## Зачем это за столом

Опоры напоминают всем, ради чего идёт охота. Когда охотник готов переступить черту, именно Убеждённости должны заставить его засомневаться. А ещё они дают Рассказчику того, кого можно подвергнуть опасности, — используйте это, чтобы сделать историю личной.

## Решите

- Кого из обычной жизни охотник защитит любой ценой?
- Какому правилу он следует, потому что этот человек существует?
- Есть ли у вашей ячейки общие **Принципы хроники** (Chronicle Tenets) — черты, которые группа договорилась не переступать? Запишите и их.

## Принципы хроники \{#chronicle-tenets}

**Принципы хроники** (Chronicle Tenets) — принципы, которыми группа договорилась руководствоваться в общей продолжающейся истории, или **хронике**. Запишите здесь общие договорённости, например «Защищать случайных свидетелей» или «Рассказывать ячейке о находках». Они относятся ко всей группе, а не к Убеждённостям одного охотника; согласуйте с Рассказчиком их роль в этой хронике Охотника, не перенося сюда правила Человечности и Пятен из Вампира.
