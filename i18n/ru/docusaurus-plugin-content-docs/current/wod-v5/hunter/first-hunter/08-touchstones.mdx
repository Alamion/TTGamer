# Опоры и убеждения

_Шаг 8 из 9_

:::tip[Коротко]
Назовите одну или две **Опоры** — реальных людей из жизни охотника — и дайте каждой **Убеждение**: правило, по которому охотник живёт ради этого человека.
:::

## Зачем это за столом

Опоры напоминают всем, ради чего идёт охота. Когда охотник готов переступить черту, именно Убеждения должны заставить его засомневаться. А ещё они дают Рассказчику того, кого можно подвергнуть опасности, — используйте это, чтобы сделать историю личной.

## Решите

- Кого из обычной жизни охотник защитит любой ценой?
- Какому правилу он следует, потому что этот человек существует?
- Есть ли у вашей ячейки общие **Принципы хроники** — черты, которые группа договорилась не переступать? Запишите и их.
