# Справочник по «Охотнику»

:::tip[Коротко]
Быстрые подсказки для игры: все части листа, Безысходность (Desperation) и Опасность (Danger) ячейки, Достоинства и недостатки, оружие и снаряжение и двуязычный глоссарий. Кредо (Creed), Мотивы и Грани перечислены там, где их выбирают: шаги [3](../first-hunter/03-creed-drive.mdx) и [6](../first-hunter/06-edges-perks.mdx).
:::

Общий движок (кубики, характеристики, урон) описан в разделе [Общие правила](../../rules/).
