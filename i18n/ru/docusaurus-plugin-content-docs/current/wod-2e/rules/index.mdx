# Справочник правил

Правила описывают, как возможности и меняющееся состояние персонажа влияют на действия с неопределённым исходом. Эти страницы объясняют значения общего листа WoD 2e; сеттинг или конкретная игра могут добавлять исключения, сверхъестественные способности и свои варианты снаряжения.
