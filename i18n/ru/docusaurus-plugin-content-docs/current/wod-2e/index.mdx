# Мир Тьмы — вторая редакция

Мир Тьмы второй редакции — классическая система ролевой игры, в которой игроки описывают действия персонажей и бросают наборы десятигранных кубиков, когда исход неизвестен. Рассказчик описывает мир, играет остальных действующих лиц и определяет, какие правила подходят к ситуации.

Этот справочник объясняет общий полный лист WoD 2e и его краткий вид на сайте: описание персонажа, числовые параметры, расходуемые ресурсы, снаряжение и развитие. Сеттинг добавляет свои варианты и исключения: например, [конверсия для «Звёздных войн»](../star-wars-wod-2e/index.mdx) меняет добродетели и использование Воли. Эти изменения не относятся к общему листу.

Работа с элементами управления описана в [руководстве по листу](../guide/sheet.mdx).
