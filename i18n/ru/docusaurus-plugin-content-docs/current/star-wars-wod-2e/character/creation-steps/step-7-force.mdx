## Шаг 8: Навыки и Техники Силы (опционально)

Если ваш персонаж **чувствителен к Силе** (имеет Достоинство Force Sensitive или эквивалент), вы можете потратить Очки Свободы на покупку Навыков и Техник Силы.

- **Навыки Силы** стоят 3 Очка Свободы за пункт.
- **Техники Силы** стоят 2 Очка Свободы каждая (требуется хотя бы один пункт в соответствующем Навыке Силы).
- Все пять Навыков Силы начинаются с **0**.

| Навык Силы      | Управляет                                                                         |
| --------------- | --------------------------------------------------------------------------------- |
| **Control**     | Силы, воздействующие на ваше тело — лечение, игнорирование боли, сила             |
| **Dynamism**    | Силы, воздействующие на энергию — сдерживание бластерных выстрелов, молния Ситхов |
| **Rapport**     | Силы, воздействующие на разум — внушение, успокоение зверей, чтение мыслей        |
| **Sense**       | Силы восприятия — осознание, ясновидение, зондирование памяти                     |
| **Telekinesis** | Силы движения — перемещение объектов, сжатие, силовые броски                      |

См. [Сила](../force.mdx) для полного списка Техник Силы и правил.
