# Значения, формулы и условия

:::tip[Коротко]
Каждое поле хранит значение под ключом. Поля с одинаковым ключом делят одно значение — в том числе между страницами. Формулы считают числа и тексты по этим ключам, а условия показывают элементы, только пока значение совпадает или формула выполняется.
:::

## Где хранится значение \{#value-source}

**Где хранится значение** выбирает, где живёт значение поля:

- **Своё значение (в шаблоне)** — поле хранит собственное значение в документе;
- значение, которое игра уже ведёт для документа, — **Характеристики**, **Ресурсы**, **Сведения о персонаже**. Тогда поле показывает и меняет это значение, и кубики, другие страницы и остальной лист видят то же число. Тип поля следует за значением игры.

Страница даёт имя документу через одно поле: выберите у текстового поля **Сведения о персонаже → Name**. Без такого поля в списке документов видно только тип, а броски кубиков идут без имени; пока поля нет, редактор напоминает об этом под страницей. Текстовое поле, которое лишь называется «Имя», хранит своё значение и документ не называет. У страницы своего типа нет сведений о персонаже: выберите у текстового поля **Имя документа**. Набранное в нём переименовывает документ, ссылки на него продолжают работать, а переименование в окне документов видно в поле. Документ без имени бросает кубики под именем своего типа.

При смене места хранения поле сохраняет своё положение и вид: ширину в колонках, условие показа, настройки подписи и текст подсказки. Настройки, которых у нового вида значения быть не может, откладываются, а экранный диктор их называет; вернёте прежний вариант до закрытия редактора — они вернутся.

## Общий ключ значения \{#shared-value-key}

Каждое своё значение хранится под ключом — по умолчанию это идентификатор самого поля. **Общий ключ значения** задаёт ключ вручную: строчные латинские буквы, цифры и дефисы (`reputation`, `ship-name`).

Поля с одинаковым ключом делят одно значение:

- на **одной странице** два поля с ключом `reputation` показывают одно число, и изменение одного меняет другое;
- на **разных страницах** одного документа поле сохраняет значение, когда читатель переключает страницу: краткая карточка и полный лист могут показывать одну `reputation`;
- ключ, совпадающий со значением игры (например `strength`), связывает поле с этим значением.

Удаление поля никогда не стирает его значение: верните поле с тем же ключом, и значение окажется на месте. У таблиц и списков есть свой общий ключ для их строк.

## Формулы \{#formulas}

**Вычисляемое значение** показывает число или текст, посчитанные из других значений. В формулах можно использовать ключи значений, числа, тексты в двойных кавычках, `+ - * /` и скобки:

```text
passion + self-control
max(0, reputation - 2)
willpower.max
```

У значений с текущим и максимумом `.current` и `.max` выбирают одно из них. Текстовые поля и выборы читаются как текст, переключатели — как 1 или 0. [Трекер](./elements.mdx#trackers) читается как число: значение самого глубокого отмеченного уровня или число отмеченных клеток, если его итог считает количество; 0, пока ничего не отмечено; значение уровня-слово («Out») — не число. Из нескольких копий считается та, что отмечена глубже всех. Встроенный трек игры читается по своему имени (`health`): его штраф за раны или число отмеченных клеток у трека без штрафов (здоровье и сила воли V5). Так `{max(1, dexterity + wounds)}d10` уменьшает пул по мере отметки ран.

| Запись                         | Что делает                                                                                                                          |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `min(a, b, …)`, `max(a, b, …)` | Наименьшее или наибольшее значение.                                                                                                 |
| `ceil(x)`, `floor(x)`          | Округляет вверх или вниз: `ceil(potency / 2)`.                                                                                      |
| `round(x)`, `abs(x)`           | Округляет до целого; убирает знак минус.                                                                                            |
| `< <= > >= = !=`               | Сравнивает два значения: 1 — верно, 0 — неверно. Тексты сравниваются через `=` и `!=`. Одно сравнение на часть.                     |
| `and(…)`, `or(…)`, `not(x)`    | Объединяет условия: значение выполняется, когда оно не 0 и не пустое.                                                               |
| `if(условие, то, иначе)`       | Один из двух результатов: `if(potency >= 3, "Нет", "Половина")`. Считается только выбранный результат.                              |
| `"текст" & значение`           | Склеивает тексты и числа: `"СК " & potency`.                                                                                        |
| `rating(list, "Имя")`          | Рейтинг записи списка с этим именем, 0 — если её нет. Список, следующий каталогу, находит запись по любому её имени на любом языке. |
| `row.column`                   | Внутри кнопки строки: значение этой строки в колонке (см. [Кнопки](./elements.mdx#buttons)).                                        | Редактор подсказывает известные ему ключи. Формула с ошибкой, ссылка на несуществующее значение или зависимость от самой себя попадают в список проблем; на странице сломанная формула объясняет причину вместо неверного числа. |

## Пределы из значений \{#limits-from-values}

Рейтинг или число может брать максимум из значения или формулы: **Максимум из значения или формулы** со значением `willpower.max` держит рейтинг не выше текущего максимума. Встроенные части страниц берут максимум так же, а встроенные ресурсы — ещё и минимум (**Минимум из значения или формулы**). Если предел опускается, страница показывает значение обрезанным, но хранит прежнее; поднимите предел — и старое значение вернётся.

## Условия показа \{#display-conditions}

**Показывать только при условии** скрывает элемент, пока не выполнено его **Условие**:

- **Значение совпадает**: **Ключ значения** называет значение, **Сравнение** выбирает «равно» или «не равно», **Значение** — с чем сравнивать (`true`, `false`, число или текст);
- **Формула выполняется**: элемент виден, пока [формула](#formulas) даёт число, отличное от 0, или непустой текст — например, `rating(disciplines, "Blood Sorcery") > 0`. Формула, которую нельзя посчитать, скрывает элемент и попадает в список проблем.

Редактор всегда показывает элементы с условием — заштрихованными — и сообщает, выполнено ли условие на пробных данных. Скрытие никогда не удаляет значения элемента.

## Каталоги \{#catalogs}

Поле **Выбор** может брать варианты из каталога игры — оружие, достоинства, виды. Выбор записи может заполнить другие поля страницы её сведениями (урон, цена, описание): укажите, какое сведение в какое поле. Заполненные значения — копии; читатель может их менять.

### Текст из каталога \{#from-catalog}

Поле **Текст** может показывать текст записи каталога: включите **Из каталога**, выберите **Каталог**, укажите в **Запись по значению** значение, где хранится запись (выбор, привязанный к каталогу, или текст с именем записи на любом языке), и выберите **Текст** — проклятие клана, описание типа хищника или текстовую колонку вашего каталога. **Другой текст, пока выполняется формула** переключает на второй текст, например на вариант проклятия, пока включён переключатель. **Показывает** выбирает способ:

- **Подсказку, пока читатель не напишет своё**: текст стоит в пустом поле; ввод заменяет его, а очищенное поле снова показывает подсказку;
- **Только текст**: поле показывает текст, вписать в него нельзя; ничего не сохраняется.

Имя, которому не соответствует ни одна запись, ничего не показывает.

### Ваши каталоги \{#your-catalogs}

Свои каталоги создаются в [библиотеке](./library.mdx): **Новый каталог** в сеттинге или на правилах, если им должны пользоваться все сеттинги на этих правилах. Каталог — это небольшая таблица: у каждой записи есть **Название** и значение в каждой вашей колонке — **Текст**, **Число**, **Флажок** или **Запись каталога**. Добавляйте записи по одной или **Вставьте строки**, скопированные из электронной таблицы: одна запись на строку, сначала название, затем колонки по порядку. Смена типа колонки предупреждает, прежде чем очистить неподходящие значения.

Выбор каталога показывает каталоги **этого сеттинга**, затем каталоги его правил, затем каталоги самой игры. Страницы другого сеттинга или других правил ваш каталог не видят. Каталог используется в трёх местах:

- поле **Выбор**: выбор записи заполняет поля, с которыми вы сопоставили её колонки;
- колонка таблицы с типом **Выбор**: откройте **Настройки** колонки; её колонки заполняют только другие колонки той же строки;
- список с именованными записями: **Подсказки из каталога** предлагают записи, пока читатель набирает название, а **Значение из** копирует колонку в запись: числовую — в число, рейтинг или текущее значение ресурса, текстовую — в текст, флажок — во флажок. Название не из каталога по-прежнему можно ввести.

Колонка **Запись каталога** говорит, какой записи другого каталога принадлежит каждая запись, — обряд своей реликвии, сила своей дисциплине: выберите каталог колонки под её типом, затем запись в каждой ячейке. Ячейка, чья запись удалена, сохраняет значение и помечается.

**Ограничить по родителю** у выбора из каталога держит строки в пределах родителей на странице: укажите **Список родителей** (список, записи которого следуют каталогу родителей), **Деталь с родителем** (колонку записи) и, если у записей есть уровни, **Деталь с уровнем**. Тогда выбор предлагает только записи родителей из списка и не выше рейтинга каждого родителя; если родителей в списке нет — всё. Строка, выбранная до того, как рейтинг упал, остаётся и помечается как «выше» родителя. Встроенные списки строк игры (силы V5) берут такое же ограничение в своих настройках.

Документ помнит, какую запись выбрал: переименование записи меняет её на всех листах. Удаление записи или всего каталога оставляет выбранное название на листах, а поля возвращаются к своему списку вариантов. Перенос каталога туда, где его не увидят некоторые страницы, сначала подтверждается и называет эти страницы. Каталоги самой игры видны в библиотеке только для чтения.
