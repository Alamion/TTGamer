# Shared Rules

:::tip[In short]
Three pages cover everything the V5 lines have in common: how a roll works, what your traits mean, and how harm and Willpower are tracked. Each line adds its own twist on top.
:::

These pages are written for players of any V5 line. When a line changes something, its own documentation says so and links back here.
