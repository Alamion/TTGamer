# Glossary

:::tip[In short]
The terms you will hear at the table, with the Russian names used on this site.
:::

| English            | Русский            | Meaning                                                |
| ------------------ | ------------------ | ------------------------------------------------------ |
| Cell               | Ячейка             | The group of hunters played by the players             |
| The Reckoning      | Воздаяние          | The moment a person learns monsters are real           |
| Creed              | Кредо              | How a hunter fights                                    |
| Drive              | Мотив              | Why a hunter keeps hunting                             |
| Redemption         | Искупление         | What brings a hunter back from Despair                 |
| Edge               | Грань              | A special resource, knack, or gift                     |
| Perk               | Умение             | An improvement to one Edge                             |
| Desperation        | Безысходность      | Shared rating; extra dice when the hunt is on the line |
| Danger             | Опасность          | Shared rating; how exposed the cell is                 |
| Despair            | Отчаяние           | A hunter whose Drive has broken                        |
| Touchstone         | Опора              | A person the hunter protects                           |
| Conviction         | Убеждение          | A rule the hunter lives by                             |
| Superficial damage | Поверхностный урон | Harm that fades quickly                                |
| Aggravated damage  | Тяжёлый урон       | Harm that lingers                                      |
| Impaired           | Ослаблен           | Every box of a track is marked                         |
| Critical           | Критический успех  | A pair of 10s, worth four successes                    |
| Difficulty         | Сложность          | Successes needed to succeed                            |
| Specialty          | Специализация      | A narrow strength within a Skill                       |
