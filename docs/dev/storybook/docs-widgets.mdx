# Documentation widgets

## Dice

`InlineRoll` in each variant, with fixed results:

<TWWrapper>
    <p>
        simple: <InlineRoll notation={'4d10>=6f=1@7,9,3,6'} preroll /> · details:{' '}
        <InlineRoll notation={'4d10>=6f=1@7,9,3,6'} variant="details" preroll /> · formatted:{' '}
        <InlineRoll notation={'4d10>=6f=1@7,9,3,6'} variant="formatted" preroll />
    </p>
    <InlineRoll notation={'4d10>=6f=1@7,9,3,6'} variant="full" multiline preroll />
</TWWrapper>

`CharRoll` reads the open Star Wars character. Change **Dexterity**, **Blaster**, or **Self Control** below and the pools follow:

<TWWrapper>
    <p>
        Dexterity + Blaster: <CharRoll attr="Dexterity" skill="Blaster" /> · Self Control:{' '}
        <CharRoll params={['virtues.Self Control.value']} />
    </p>
    <TemplateFragment node="attributes" />
    <br />
    <TemplateFragment node="skills" />
    <br />
    <TemplateFragment node="force-virtues" />
</TWWrapper>

The dice pool builder (`WodTab` + `RollControls`):

<TWWrapper>
    <div className="max-w-[375px]">
        <WodTab />
        <RollControls />
    </div>
</TWWrapper>
