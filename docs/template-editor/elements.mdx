# Elements

:::tip[In short]
Sections and field groups arrange the page; fields, tables, lists, and trackers hold values. Containers split into up to four columns, and a section or group can link to a documentation page.
:::

## Sections \{#sections}

A section is a large block with a heading and a colored bar. Readers fold and unfold it; **Starts collapsed** keeps it folded until the reader opens it once (the choice is then remembered). Neighbouring sections alternate the bar's color by themselves.

## Field groups \{#groups}

A field group is a titled card inside a page or section. **Show title** hides the heading while keeping the card; **Collapsible** lets readers fold it (only with a visible title).

## Documentation link \{#documentation-link}

Sections and field groups take a **Documentation link**: a **?** next to the heading opens that page in a new tab. Two forms are accepted:

- **A page of this site's documentation**: the address from the browser after the domain, starting with `/docs/`, for example `/docs/wod-v5/rules/dice-pools#reading-the-dice`. The part after `#` jumps to a heading: open the page, hover a heading, and copy its link. Readers get the page in their own language — write the English address and Russian readers land on the Russian page.
- **An external page**: a full address starting with `https://`, for example a wiki article.

Anything else — an address without `/docs/`, `http://`, or another scheme — is listed as an issue and is not shown on the page.

## Columns \{#columns}

Pages, sections, and groups lay out their elements in 1 to 4 **Columns**. With **Equal column widths** off, each column gets a width: widths are proportional, so 2 and 1 make the first column twice as wide. Without pinned elements, elements fill the columns in order. **Column in parent** pins an element to one column; once any element of a container is pinned, the elements left on **Auto** stack in the first column. **Spans columns** stretches an element over 2 to 4 columns — a wide field beside a narrow one, or a full-width row; spans work while no element of the container is pinned. On a phone every container shows one column. An empty column shows a drop zone in the editor.

## Fields \{#fields}

A field holds one value. Its **Field label** is shown next to it (**Show label** hides it), **Help text** explains it on hover, and **Required** marks it for the reader without blocking anything. **Label position** puts the label **Above the value** in small grey type, or **Beside the value** in the larger type of the sheet's attribute rows; ratings and derived values start beside, other fields above. An image always keeps its label above: the picture and its upload controls need the whole width.

| Type                   | What the reader gets                                                                                                                                                                                     |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Text**               | A line of text, or a larger box with **Multiline**; a **Placeholder** shows while it is empty.                                                                                                           |
| **Number**             | A number kept within **Min**, **Max**, and **Step**; arrow keys step it.                                                                                                                                 |
| **Toggle**             | A dot: transparent when off, filled when on.                                                                                                                                                             |
| **Choice**             | One option from a list, or several with **Allow multiple values**; **Hide unselected options** shows only the chosen ones until the reader opens the list. A choice can take its options from a catalog. |
| **Rating**             | A row like the sheet's attributes: dots or a number from **Min** to **Max**; see [Ratings](#rating).                                                                                                     |
| **Resource**           | A current value and a maximum, such as a pool of points.                                                                                                                                                 |
| **Derived value**      | A number computed by a [formula](./values.mdx#formulas); readers cannot type into it.                                                                                                                    |
| **Image**              | A picture from the device or an `https://` address.                                                                                                                                                      |
| **Document reference** | Links to other documents of the allowed types; readers open them from the field; see [Document references](#references).                                                                                 |

## Ratings \{#rating}

A rating reads like an attribute row on the shipped sheets: the label on the left, the dots on the right. **Presentation** chooses **Dots** (one dot per point) or **Number** (a number box). Templates saved with the older "boxes" presentation open as dots and keep their values.

- **Min** is a floor, not a dot: the dots up to it stay filled in a darker shade, and the reader cannot go below it.
- **Max** sets the number of dots. A [maximum from a value or formula](./values.mdx#limits-from-values) replaces it while it can be computed, up to 100 dots; when it drops below the stored value, the value is kept and shown in parentheses until the maximum rises again.
- **Text input (for example a specialization)** adds a line between the label and the dots; on narrow screens it moves under the label.
- **Show current / maximum** writes "3 / 5" after the dots; with **Number** it adds "/ 5" inside the number box, like a resource whose maximum cannot be edited.
- **Die symbol (roll the rating)** rolls the value the way the document's game rolls an attribute of the same value; the roll names the rating.
- **Flags** (dots only): **S** (specialization), **P** (practiced), and **E** (experienced) add the same switches as a trait row. They change the roll only where the game's dice rule uses them: the Star Wars sheet does, V5 does not.

Formulas and display conditions read the rating's number; its text and flags do not change it. Ratings with the same [shared value key](./values.mdx#shared-value-key) share the number, the text, and the flags.

## Document references \{#references}

**Allowed document kinds** lists the kinds of the page's own setting, each once: the setting's own kinds (a Hunter page offers the hunter), the ruleset's shared kinds (the V5 mortal), and the kinds you created in that setting or for the whole ruleset. Kinds of other games and of your other settings are not offered, even when they have the same name. When two offered kinds would read the same, the setting is added to the name; your own kind of the same name in the same setting is marked "(yours)". A new reference points at the page's own kind.

On the sheet, the search offers the reader's documents of those kinds from the same setting, never the document itself.

- A reference saved earlier may point at a document of another setting. It stays: the entry shows the document's title, notes "outside this setting", opens it, and can be removed. Once removed, that document is not offered again.
- A document that was deleted shows "Linked document no longer exists" until the reader removes it.
- A kind the setting no longer has (a deleted type, or one from another setting) stays checked and is marked "(unavailable)", and the template's problems list names it. Uncheck it to drop it; the last kind cannot be unchecked.

## Tables \{#tables}

A table holds rows of values with the same columns; every column is a field. **Min rows** and **Max rows** bound how many rows readers can add.

## Lists \{#lists}

A list holds entries added one by one: your own entries, or a list the game already keeps for the document (skills, merits and flaws, equipment).

A list with its own entries sets up one **Entry**: pick its type — text, number, toggle, choice, rating, resource, document reference, or image — and its settings, as for a field of that type. Every entry the reader adds is a copy of it. A new list starts with the classic trait row: a rating with dots, the S/P/E flags, and a die.

- **Entries are named**: each entry gets a name the reader types, such as "Firearms" next to its dots. Turn it off for lists of notes or pictures: then each entry shows the entry's label, or nothing when **Show label** is off.
- **Preset entries** start a new document with ready rows: their names, and their numbers where the entry holds one. Presets need named entries.
- Each entry has its own remove button: at the end of the row, or above a block such as a picture or several lines of text.

Changing the entry type or turning names off can hide values readers already stored. **Save** then lists how many values or names each list would stop showing and asks first. The values stay stored: changing the entry back shows them again, except for entries edited in between.

## Trackers \{#trackers}

A tracker shows the game's health or damage levels with their penalties, as a table of levels or a line of boxes.

## Built-in page parts \{#built-in-parts}

Shipped pages also use built-in parts: traits, resources, and lists the game itself keeps for the document. They look like the fields above and store their values in the document, so every page of that document shows the same numbers.
