# Template editor

:::tip[In short]
A template is the layout of a document's page. Open **Library** on the [character sheet](/universal_sheet), select a page in the [library tree](./library), open it in the editor, and change it on the page itself: select an element to see its settings, drag it to move it, press **Save** when the issues list is empty.
:::

Every document opens on a page: which blocks it shows, where they sit, and which values they keep. The pages that come with a game are **shipped pages**; you can change them, copy them, or build your own from scratch. The **?** next to a setting in the editor opens the matching part of this guide.

## The three areas \{#areas}

| Area         | What it is for                                                                                           |
| ------------ | -------------------------------------------------------------------------------------------------------- |
| **Outline**  | The tree of every element on the page. Click a row to select an element; drag the handle to move it.     |
| **Page**     | The page exactly as a reader sees it, filled with sample data. Click an element to select it.            |
| **Settings** | Everything the selected element can do, in the same groups for every element: see [Settings](#settings). |

Drag the line between two areas to make the outline or the settings wider; the page keeps at least the width of a phone. A focused line also moves with `←` and `→` (`Shift` for bigger steps), and `Home` or a double click puts it back. The widths are remembered on this device for every page you edit.

On a narrow screen the three areas become tabs. Elements hidden by a display condition stay visible in the editor, hatched, so you can still select them.

The sample data is only for looking: dots, boxes, and text you change on the editor's page never reach your documents.

## Settings \{#settings}

The settings of the selected element start with its actions (move up, move down, duplicate, remove), then its kind and full name. Below them the settings come in the same groups, in the same order, for every element; a group the element has nothing for is left out:

| Group                   | What it holds                                                                  |
| ----------------------- | ------------------------------------------------------------------------------ |
| **Content**             | What the element shows: its kind, title or label, help text, options, entries. |
| **Value**               | Where the value is stored: the source, the value key, catalogs.                |
| **Limits and formulas** | Bounds and every formula: minimum and maximum from values, derived values.     |
| **Look**                | How it is drawn: columns, presentation, display, tracker look.                 |
| **Visibility and help** | When it shows and what helps the reader: conditions, documentation, folding.   |

Fold a group with its heading; the editor keeps the groups you opened while you select other elements. A folded group that holds a problem of the element shows how many.

Every setting is named above its box. A formula box carries an **fx** mark and says right under it what the formula reads, or what is wrong with it. A value key starts with **#**: it is a name for the value, not text readers see.

## Edit and preview \{#preview}

The **Edit / Preview** switch at the top shows the page without editor marks. In **Preview** you choose the data it shows:

- **Open document** — the document open on the sheet, if it fits this page;
- a shipped **example** for the document type, when the game provides one;
- **Blank document** — every value empty, to check how the page starts.

The preview never changes the chosen document.

## Arranging elements \{#arranging}

- **Add**: every **+** between elements and every empty column inserts a new element there — a [group](./elements#sections), a field, a [list](./elements#lists), or a tracker. A group added on the page is a section, inside another group a card.
- **Move**: drag an element by its chip on the page or by its handle in the outline. A line marks the nearest place it can go — between elements, inside a group, or in an empty column — even while the pointer is over another element. Rest a moment, and the page shows the element in its new place, with a dashed line where it was. Release to move it (one step of **Undo**), or press `Escape` to leave everything as it was. Near the top or bottom edge the page scrolls. On touch screens use the move buttons in the settings.
- **Keyboard**: the shortcuts work with any keyboard layout.

| Keys                      | Action                                         |
| ------------------------- | ---------------------------------------------- |
| `Ctrl+X`                  | Cut                                            |
| `Ctrl+C`                  | Copy                                           |
| `Ctrl+V`                  | Paste                                          |
| `Ctrl+D`                  | Duplicate                                      |
| `Delete`                  | Remove                                         |
| `?`                       | Show this list of shortcuts                    |
| `Ctrl+click`              | Add an element to the selection or take it out |
| `Shift+click`             | Select the elements in between                 |
| `Esc`                     | Clear the selection                            |
| `Alt+↑`                   | Move up                                        |
| `Alt+↓`                   | Move down                                      |
| `Alt+←`                   | Move out of the group                          |
| `Alt+→`                   | Move into the group above                      |
| `Alt+Shift+←`             | Move to the previous column                    |
| `Alt+Shift+→`             | Move to the next column                        |
| `Ctrl+Z`                  | Undo                                           |
| `Ctrl+Shift+Z` / `Ctrl+Y` | Redo                                           |

On a Mac, `⌘` stands for `Ctrl` and `⌥` for `Alt`, and `⌫` removes too. The editor's **Keyboard shortcuts** button (or `?`) shows this list in the editor.

Undo covers every change since the editor opened; typing in one field counts as one step.

## Copy and paste \{#copy-paste}

Select an element and press `Ctrl+C` to copy it, `Ctrl+X` to cut it, and `Ctrl+V` to paste. The copy lands right after the selected element, at the end of a selected group, or at the end of the page when nothing is selected; if a group is nested too deep for it, it goes to the nearest place that fits. Each paste is one step of **Undo**, and the pasted elements become the selection.

- **On the same page** a copy is named like a duplicate and keeps its values apart from the original.
- **On another page** — after closing the editor, in another tab, or from text another author shared — the names stay as they were, and so do value keys the page does not use yet. Formulas and display conditions inside the copy read the copy's own elements.
- Anything the page cannot show (a value it lacks, a game list of another system) appears in the issue list, pointing at the setting to fix.
- Text that is damaged or comes from a newer editor is refused with a message; nothing changes. In a text box, copy and paste work on text as usual.

## Several elements at once \{#selection}

`Ctrl+click` an element on the page or in the outline to add it to the selection or take it out; `Shift+click` selects the elements in between. `Delete`, `Ctrl+D`, copying, the move keys, and dragging then act on all of them as one step; an element inside a selected group goes along with the group. `Esc` clears the selection (a second `Esc` closes the editor).

With several elements selected, the settings show how many there are, their names (click one to open it alone), and the settings they all have, such as the display condition, **Required**, or the column span. A setting whose values differ says **Mixed**; changing it sets it on every selected element.

## Element menu \{#menu}

Right-click an element on the page or in the outline — or hold a finger on it on a touch screen — to open its menu: cut, copy, paste, duplicate, the moves, and remove, each with its keys. Actions that do not fit right now are greyed out. On a touch screen the menu also has **Add to selection**. Right-click empty space on the page to paste at its end.

## Saving and issues \{#saving}

Changes stay in the editor until you press **Save**. Above the button, the editor lists what would make the page break, in plain words, naming the element: an empty label, a list entry or table column without a name, a formula that does not parse, a value it cannot find, a broken documentation link. Click an issue: the editor selects the element, opens its settings group, and puts the cursor in the setting to fix — inside a table column too. **Save** stays disabled while the list has such issues. If saving still finds a value that is not allowed, it says which element and setting, and nothing is saved.

Closing the editor with unsaved changes asks before throwing them away.

## Shipped pages \{#shipped-pages}

Changing a shipped page saves your version of it; every document using that page shows your version at once. **Reset to original** in the library brings the original back — documents keep their values. Shipped pages cannot be deleted; **Duplicate** one to start your own page from it.
