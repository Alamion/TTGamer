# Document types and settings

:::tip[In short]
A page belongs to one document type in one setting. You can move it, give your setting its own document types built from pages, and build whole settings on the rules this site already supports.
:::

## Moving a page \{#moving-a-page}

**Type and setting**, at the top of the editor, says which documents a page is for. Choose another entry to move the page: to another type of the same game, to one of your own types, or to a character of your own setting.

When you save a moved page:

- documents that opened on it and can no longer use it go back to their default page — the editor asks first and says how many;
- if it was the page of one of your settings, that setting forgets it; if the setting you moved it to has no page for that character yet, it becomes that page;
- if it was the default page of one of your document types, the type takes another of its pages.

Values tied to game data that the new type does not have are listed as issues before saving: switch those fields to custom values or remove them.

Shipped pages stay where they are; so do the first page of a new document type and a setting's page opened from the setting.

## Your own document types \{#document-types}

**New document type** in the template library creates a type — an organization, a ship log, a location — in any setting, and opens its first page. Its documents appear in **Create document** next to the setting's own types. Every value of such a document is kept with the document, so changing or deleting the type's pages never loses data: a document whose type is gone opens on a page listing its stored values.

## Your own settings \{#settings}

**New setting** builds a setting on rules the site supports — World of Darkness 2nd Edition or 5th Edition. Its characters follow those rules (dice, limits) on a page you design with **Page: Character**, and your document types can belong to it.

## Sharing by file \{#files}

**Export type** saves a document type with its pages in one file; importing it in the template library installs it. A document of your own type carries its type inside its file, so it opens where the type is not installed.
