# World of Darkness 5th Edition

:::tip[In short]
V5 is one set of rules shared by several modern horror games. Learn the core once in **Shared rules**, then pick a line. Right now you can play **Hunter: the Reckoning**.
:::

The fifth edition of the World of Darkness is a family of games about ordinary-looking people in a world where monsters are real. Each game ("line") puts you in a different role — hunters who fight the monsters, or the monsters themselves — but they all use the same engine: pools of ten-sided dice, simple dot ratings, and damage that wears you down.

This section is split the same way. **Shared rules** explain the engine every line uses. Each line has its own section with a quickstart, a guided character creation path, and a reference for its special rules.

| -------------------------- | --------------------------------- |
| Hunter: the Reckoning 5e   | Sheet and documentation available |
