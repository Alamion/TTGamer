# Predator Types

:::tip[In short]
A predator type is a vampire's usual way of feeding. Each gives a choice of **Specialty**, one **Discipline dot**, and some **Advantages** and **Flaws**; some also change Humanity or Blood Potency, or are closed to a clan.
:::

Search by name. Select a row for its summary and what it gives. On the sheet, the **Predator type** field suggests these names, and **What the predator type gives** shows the chosen type's grants.
