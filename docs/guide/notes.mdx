# Notes \{#notes}

:::tip[In short]
**New** → **Note** (under **General**) makes a note for any game. Write in markdown: every line is its own paragraph, and the result shows beside the text. **Done** or `Esc` turns it into a page to read; **Edit** or `Ctrl+E` brings the text back. Callouts that start folded keep a long note tidy, `` `dice: 2d10` `` becomes a roll, and `[[Name]]` links to another document.
:::

## Creating a note \{#creating}

Press **New** on the [character sheet](/universal_sheet), type `note`, and press `Enter` twice (or give it a name first). A note belongs to no game, so it is under **General** whatever rules you have, and it lives in the [documents window](./documents/) like any other document: in folders, in tabs, beside a character sheet.

A new note opens ready to write, with the cursor in its text. **How notes work** in the same dialog is an example note that shows everything below.

## Reading and editing \{#editing}

A note opens as a page to read. **Edit** shows its text; **Done** goes back. On a wide pane the text and the result stand side by side, and the divider between them moves; on a narrow one **Source** and **Result** switch between them.

| Keys                        | What they do                                           |
| --------------------------- | ------------------------------------------------------ |
| `Ctrl+E` (`Cmd+E` on a Mac) | Switch between reading and editing                     |
| `Esc`                       | Stop editing                                           |
| `Ctrl+B`, `Ctrl+I`          | Bold, italic around the selection                      |
| `Ctrl+K`                    | A link around the selection, with the address selected |
| `Ctrl+L`                    | Turn the selected lines into checklist items, or back  |

The toolbar has the same commands, plus **Callout**, **Folded callout**, and **Image**. Everything is saved as you type, and the browser's undo (`Ctrl+Z`) works in the text. A note holds up to 300,000 characters (about 45,000 words).

## What a note understands \{#syntax}

Notes read the markdown Obsidian writes, so text moves between them without changes. One difference from strict markdown: **every line is its own paragraph**, so you never need a blank line to start a new one.

```markdown
# Scene one

## The docks

Rain at night; Ines waits by the crates.
**Bold**, _italic_, ~~struck out~~, ==highlighted==, `code`, and [a link](https://example.org).
```

```markdown
- [ ] Prepare the map
- [x] Motives of the gang
    - Bruno owes money

1. Numbered lists work too
```

```markdown
| NPC          | Wants            |
| :----------- | :--------------- |
| Ines Ruiz    | money            |
| Bruno Kessel | to be left alone |
```

```markdown
> "Come alone." — the letter
```

Checklist items tick right on the page you read. HTML written in a note is shown as text and never runs; links work only for web, mail, and in-page addresses.

## Callouts and folding \{#callouts}

A callout is a quote with a type and a title. A `-` after the type makes it start folded, a `+` starts it open but foldable; without either it cannot fold. Use folded callouts for history, twists, and anything you open only when the players get there.

```markdown
> [!info]- History of the docks
> Built by the guild a century ago.

> [!spoiler]- What is really going on
> The guard is the thief.

> [!warning]+ What the players see
> Two guards, one asleep.
```

A line that opens a callout always starts a new one, even right after a quote or another callout. Obsidian joins such lines into one block, so leave a blank line between callouts if the note will go there.

Folding is only how you read the note: it is never written into the text. Types with a color of their own are `note`, `info`, `tip`, `success`, `warning`, `spoiler`, `danger`, `bug`, and their Obsidian names; any other word shows as a plain callout.

## Rolls \{#rolls}

Code that starts with `dice:` is a roll, written as in the Obsidian Dice Roller plugin. Press it and the [dice roller](./dice-roller) rolls exactly that notation: it lands in the history, is named after the note, and is shared to Discord or Matrix if you [share rolls](./roll-sharing/).

```markdown
Ambush: `dice: 6d10>=6`
```

Notation the dice roller cannot read stays as code with a wavy underline; point at it to see why.

## Pictures \{#pictures}

Paste a screenshot into the text, or press **Image** and pick files: the picture is stored on this device with the note, up to 2,048 pixels on its long side, and its name goes where the cursor was as `![[name]]`. A picture from the web works by its HTTPS address: `![Map](https://…)`.

```markdown
The docks: ![[docks map.png]]
```

Delete the line and leave the text, and the stored picture is freed; undo before that brings it back. A note holds up to 100 pictures.

## Links between documents \{#links}

`[[Name]]` links to the document of that name: a note, a character, a group — any document on this device. Type `[[` while editing and the documents whose names hold what you type are suggested, the nearest first; arrows choose, `Enter` or `Tab` writes the link. After a name, `#` suggests its sections: a note's headings, or the parts and fields of a sheet.

```markdown
Meet [[Ines Ruiz]] at [[Docks#History|the old docks]].
```

- **Following.** A click opens the document, and **Back** returns to the note; `Ctrl`+click (or the middle button) opens it in a new tab. A link with `#` scrolls to that section.
- **Preview.** Point at a link, keep the keyboard focus on it for a moment, or press and hold it on a touch screen: a card shows the document's brief, or a note's first lines. Reference fields — a vehicle's crew, a group's members, **Member of** — show the same card.
- **Same names.** When several documents share a name, a link means the one nearest to the note in your folders, then the oldest. A suggestion adds the folder path (`[[World 2/Items/Sword]]`) when the name alone would mean another one.
- **Missing names.** A link to a name no document has is dashed; a click offers to create a note of that name next to this one.
- **Renaming and moving.** Rename or move a document, or make another of the same name nearer to a link, and the links that meant it are rewritten to keep meaning it; a short message says how many. **Undo** in the documents window puts back the name and only those links, and leaves your later edits alone. Deleting a document changes no text.

`![[Name]]` shows the document inside the note: a note's whole text, or a sheet's brief. `![[Name#Section]]` shows one section. An embedded document can embed one more; deeper ones, and a note that would show itself again, stay links. A picture stored in the note wins over a document of the same name.

```markdown
![[Bruno Kessel]]
![[Docks#History]]
```

**Mentioned in**, at the bottom of every note, lists the documents that link to it, each with the line around the link; a click opens that line. You can put it on your own pages from the template editor's **+** menu.

## Markdown files \{#files}

**Export** on a note saves a markdown file: its name in the front matter, the text as you wrote it. A note with stored pictures saves a zip of the file and an `images` folder. Unpack it into an Obsidian vault and the note opens there with its pictures.

**Import** takes `.md` and `.zip` files (and the usual `.json` exports): each becomes a new note, named by the `title` in its front matter or else by the file. Other front matter keys (tags, aliases, dates) are kept and written back on the next export. A file that cannot be read joins the rejected files of the [documents window](./documents/#rejected-files) with the reason.

## Markdown in your own pages \{#own-pages}

Notes are made of one **Markdown text** element, and you can put it on your own pages too: a "Location" type with a name, a region, and a markdown description. See [elements](./template-editor/elements#markdown) in the template editor guide.
