# World of Darkness 2nd Edition

World of Darkness 2nd Edition is a classic roleplaying ruleset in which players describe their characters' actions and use pools of ten-sided dice when the outcome is uncertain. The Storyteller describes the world, plays other people, and decides which rules apply to a situation.

This reference explains the generic WoD 2e full sheet and brief on this site. It covers character descriptions, rated traits, changing resources, equipment, and advancement. A setting supplies its own options and exceptions; the [Star Wars conversion](../star-wars-wod-2e/index.mdx), for example, changes Virtues and the use of Willpower. Those changes do not apply to the generic sheet.

For controls and editing, use the [sheet guide](../guide/sheet.mdx).
