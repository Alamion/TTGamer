# Documentation status archive

This is the compact archive for completed documentation planning. It keeps the active TODO small without losing the project history.

## Completed Star Wars WEG/WoD documentation

- Core mechanics, character creation, combat, equipment, creatures, vehicles, GM guidance, examples, glossary, and the Star Wars documentation landing page are complete.

## Interactive documentation support

The documentation now uses shared interactive components where appropriate: `InlineRoll`, character-derived rolls, dice-pool controls, `DataCatalog`, entity cards, and character-sheet blocks. The catalog work added reusable data/config pairs for species, alien physiology, backgrounds, merits/flaws, attributes, abilities, and Force powers.

## Rules retained as project documentation

The following rules are deliberately documented in the relevant MDX pages: one success is marginal; a botch needs at least one `1` and zero net successes; heroic soak applies; Force Points replace the Willpower role; attribute/ability limits apply; droid memory is partitioned; and freebie costs cascade by trait type.
